事实优先级：当前代码与测试 > `CURRENT_HANDOFF.md` > 稳定文档

## 状态定义

| 状态 | 含义 |
|---|---|
| 已完成 | 生产实现与当前自动证据均存在 |
| 部分完成 | 已有真实子链路，但仍缺产品要求中的字段、入口或更高等级证据 |
| 未开始 | 只有文档或预留模型，没有生产入口 |
| 待外部验收 | 代码可继续推进，但最终结论需要设备、隐私批准样本或用户确认 |

## 11. 当前最优下一阶段判断

选择 **Stage 3B：单命例交换与完整数据安全**。

依据：

1. Stage 3A 已把记录、分析、事件、分类、历史与命例生命周期的用户语义固定下来，
   “按模块导入”和冲突预览已有明确对象。

   两阶段提交，可降低后续真实案例规模扩大后的数据损失风险。
3. Stage 3B 可完全使用合成数据完成，不需要真实问真资料、账号或真机授权。
4. 本阶段不缩小最终目标；算法完整化、问真迁移、折叠屏和真机验收继续保留在清单中。
