# 领域规则

## Stage 0 已固定

- 输入显式区分公历和农历，不允许靠文本猜测。
- 性别字段当前只服务于顺逆排运，命名为 `SexForFortuneDirection`。
- 计算配置必须保存 `engineVersion` 与 `ruleVersion`。
- 结果必须回带归一化输入、计算配置、引擎证据及警告。
- 默认使用节气瞬间换年、节令瞬间换月、Tyme4j 默认子时口径。
- 大运至少输出起运时间、顺逆、起始年龄和前八步大运。

## Stage 1 数据合同

- `ABSENT` 表示来源未提供，`CLEARED` 表示用户明确清空，二者不能合并为空字符串。
- 命例稳定 ID 重复且没有修订号时返回“已存在”，不能覆盖。
- 更新必须携带期望修订号；旧修订返回冲突并保留现有数据。
- 反馈、点评、事件、快照、附件和字段证据都保存明确顺序。
- 截图来源值、软件计算值和用户采用值分别保存。
- 附件必须使用 App 私有根目录下的安全相对路径，并记录字节数和 SHA-256。
- 完整恢复当前仅允许空数据库和空附件目录；失败后回滚本次数据库写入。
- 密码加密未实现时明确拒绝，不能生成冒充加密的明文 ZIP。

## 当前明确不支持

- 农历输入转换；
- 地理位置、时区历史库与真太阳时校正；
- 多引擎裁决；
- 问真截图 OCR 与字段纠错；
- 非空库冲突合并与逐字段恢复；
- 密码加密备份；
- 真实案例导入。

调用者请求尚未支持的口径时，适配器必须明确失败，不能静默降级为公历民用时。

## 时间语义

出生时间保留到秒；`timePrecision` 表示原始材料的可信粒度。当前计算仍需要完整时间，
但不得因为填入默认秒数就把来源精度伪装为“精确到秒”。
