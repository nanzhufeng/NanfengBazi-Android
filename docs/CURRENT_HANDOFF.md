- UI 不直接调用 Tyme4j，也不自行复制历法或四柱算法。

- 测试差分引擎只存在于测试依赖，不得进入生产入口。
- Tyme4j 全局 `LunarHour.provider` 只允许在四柱反查适配器中受锁访问，并在成功、失败、取消和并发路径恢复原对象。
