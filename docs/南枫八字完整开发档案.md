> 审计日期：2026-08-23。本文只整理当前工作树、项目文档、配置、测试目录与 Git 历史可证明的事实；未把未复验的真机或外部服务写成完成。

## 项目目标

南枫八字是 Android 本地优先应用，用于录入命例、生成排盘与专业细盘、管理断事记录、导入来源资料、提供万年历与合盘、进行可控 AI 点评，并提供完整备份与可选的加密云同步。Room 是业务真值，云端只保存加密结构化快照；来源图片和附件不随云同步上传。

`app` 通过 `AppContainer` 组装仓储、引擎、备份、云同步和 ViewModel；`StageTwoViewModel` 是主要 UI 状态与用例编排点。领域算法由 `BaziEngine`/`TymeBaziEngine` 提供，持久化由 `CaseRepository`/`RoomCaseRepository` 提供，备份与云快照由 `CaseBackupService` 提供。

## 核心模块与数据流

| 流程 | 实现路径 | 关键约束 |
|---|---|---|
| 录入与排盘 | 表单 → `CaseWorkflow` → `BaziEngine.calculate()` → `CaseRepository.save()` | 同一输入、计算配置与版本化快照；预览不写入 |
| 命例详情 | 仓储聚合 → `StageTwoViewModel` → Compose | 子状态绑定 `caseId + revision`，避免跨案例错配 |
| 专业资料导入 | 系统 URI → 私有文件 → OCR/归组 → 人工确认 → 提交 | 外部 URI 不长期保存；来源/计算/采用值分开 |
| 合盘 | 两个计算结果 → `BaziCompatibilityAnalyzer` → 报告与本地历史 | 领域层生成关系、结构与证据；页面不应以模板替代分析 |
| 备份恢复 | 聚合 → ZIP/清单/哈希 → 预览 → 显式计划 → 写入 | 校验路径、容量、哈希、引用与冲突；禁止 destructive migration |
| 云同步 | `CaseBackupService.exportCloudSnapshot()` → 加密快照 → Worker | 本机 Room 为真；真实上传/恢复另行授权 |
| AI 点评 | 用户确认 → 兼容 API → 可编辑预览 → 记录保存 | 发送范围可见、密钥进 Keystore、结果不改算法真值 |

依据：`CaseWorkflow.kt`、`BaziCompatibility.kt`、`BaziCompatibilityHistoryStore.kt`、`CaseBackupService.kt`、`BaziCloudCore.kt`、`AiCommentaryFeature.kt`。

## 关键决策与原因

1. **本机优先与版本化聚合：** Room 承担业务真值，写入带 revision，防止缓存把子记录误判为空。
2. **排盘单一入口：** 使用 `BaziEngine.calculate()`，防止 Compose 或导入流程各自推算导致口径分裂。
3. **备份防御性解析与流式处理：** 大型快照不可先拼整表 JSON；预览与提交拆开，恢复计划显式化。
4. **外部能力可控：** 云同步和 AI 不替代本机事实；真实服务证据与构建证据分层。
5. **合盘以领域信号生成：** `BaziCompatibilityAnalyzer` 负责结果模型，页面只负责可读呈现，不能把“无合冲”误述为“无作用关系”。

依据：`docs/architecture-governance.md`、`docs/DATA_CONTRACT.md`、`docs/cloud-sync-contract.md`、`docs/domain-rules.md`、`core/domain/BaziCompatibility.kt`。

## 踩坑与修复

| 问题 | 根因与处理 | 防回归资产 |
|---|---|---|
| 案例切换后子记录像消失 | 父详情缓存与子状态所有权不同步；以聚合和 revision 装载 | `StageTwoViewModelTest` |
| 大库备份/同步 OOM | 全库 JSON 字符串造成连续内存峰值；改为流式编码与 IO | `CaseBackupServiceTest` |
| 取消显示成网络失败 | 取消被吞进通用异常；取消原样传播 | 云同步策略测试 |
| UI 按压区域外溢 | 表面、裁切与点击形状不一致 | `InteractionShapeContractTest` |
| 合盘出现固定化或错位表达 | 领域信号与用户文案未严格对应 | `BaziCompatibilityAnalyzerTest` 与 UI 合同测试 |

依据：`docs/app-experience-audit.md`、`docs/decision-log.md`、`docs/CURRENT_HANDOFF.md` 与对应测试。
