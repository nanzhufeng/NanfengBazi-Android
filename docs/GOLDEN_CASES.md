# 黄金样本

机器可读样本位于：

`core/engine-tyme/src/test/resources/golden-cases-v1.json`

每条样本至少包含：

- `id`：稳定标识；
- `source`：公开来源或人工边界说明；
- `input`：不含真实用户信息的结构化出生时间；
- `profile`：计算口径；
- `expected`：四柱或边界关系；
- `engineVersion` 与 `ruleVersion`；
- 真太阳时样本还必须包含算法版本、时区/offset、经纬度、校正后时间和边界标记。
- 基础排盘样本必须至少覆盖生肖、星座、日主、四柱主星、藏干及副星、十二长生、自坐、
  旬空、纳音和前后节气。

当前公开回归样本取自 Tyme4j 自身公开测试；边界样本由立春节气 API 及真太阳时跨时辰/
跨日输入生成。用户提供的问真截图只抽取了非身份化的 1992-08-24 泗阳示例：问真显示
真太阳时 11:53、四柱 `壬申 戊申 壬申 丙午`；仓库使用明确标注的县域坐标近似值，SPA
结果为 11:52:23，与截图显示分钟相差 37 秒，四柱一致。该样本只能证明当前非边界结果
对照。当前机器样本同时逐项固定该图可核对的主星、藏干副星、长生、自坐、旬空、纳音、
生肖和前后节气，但仍不能替代问真跨日、跨时辰、节气瞬间的后续真实验收。

后续接入真实问真验收案例时，完整数据应保存在加密、本地、Git 忽略的验收夹具中，不能
复制进仓库。
