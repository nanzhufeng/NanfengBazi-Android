# 南枫八字

南枫八字是面向个人案例管理与结构化研判的本地优先 Android 应用。

当前仓库已完成 **Stage 0 算法骨架**、**Stage 1 数据底座**和
**Stage 2 手机单列最小业务闭环**及 **Stage 3A 五个命例管理增量**：

- 定义出生输入、计算口径和版本化结果；
- 通过唯一入口 `BaziEngine.calculate()` 调用计算引擎；
- 使用 Tyme4j 1.5.1 作为首个适配器；
- 支持公历、农历与闰月手动录入；计算快照同时保存标准公历和标准农历转换证据，
  编辑时保留原始历法语义；
- 以公开样本建立可回归的黄金用例；
- 建立 Room Schema v6、兼容迁移、统一命例仓储和修订冲突保护；
- 建立版本化 ZIP 备份、附件哈希校验和空库恢复回滚；
- 手动录入公历出生资料，经 `BaziEngine.calculate()` 排盘后通过
  `CaseRepository` 保存；
- 在手机单列界面中完成命例列表、姓名/别名搜索和详情查看；
- 对必填校验、计算失败、保存冲突和数据库异常提供明确中文反馈。
- 支持按修订号编辑命例并重新排盘，保留旧计算快照；
- 支持普通笔记、命主反馈、师傅点评、分析记录和关键事件的增改删。
- 支持记录与事件不可覆盖的版本历史、统一分析分类，以及关键事件结构化标题和类别。
- 支持分组、标签、收藏、置顶、最近查看、四柱搜索、筛选和多种排序。
- 支持可恢复软删除与回收站、命例复制，以及新建/编辑前的重复候选提示。
- 支持同一命例保存多个出生时间候选；每个候选绑定独立计算快照，只有明确采用才切换
  当前出生输入和采用盘。
- 已接通单命例 JSON v1 严格封套、载荷哈希、系统文件往返、零写入冲突预览，以及
  无附件命例的跳过、保留两份、按模块追加和逐字段采用。
- 单命例可选择明文风险确认或密码保护；密码容器采用版本化
  PBKDF2-HMAC-SHA256 + AES-256-GCM，并在解密后继续执行原协议全部校验。
- 带来源图片的命例可选择 `.nfbcase` 附件包；包内 manifest 绑定命例文档与每个附件的
  路径、大小和 SHA-256，支持明文或独立流式密码容器。
- 命例包预览为零写入，提交时重开同一系统文件并重新认证；保留两份与范围合并都会重建
  附件身份和引用，复用恢复日志、暂存目录、原子切换与 Room 事务边界。
- 完整备份已接通未加密风险确认、独立密码容器、Android 系统文件保存和只读预览；
  预览会认证密文并校验 ZIP 路径、大小、SHA-256、数量、数据引用与附件一致性，还会
  逐命例显示当前库的稳定 ID、出生输入和四柱冲突候选。
- 完整恢复计划已具备逐例显式决策、Android 批量编辑、合并目标/范围约束和本地变化后
  的预览过期拒绝；明文和密码备份均可在最终确认后执行按原 ID 导入、保留两份、跳过
  和范围合并。
- 每个来源预览携带经领域模型重建的完整命例聚合，后续合并与提交不会只依赖冲突摘要。
- 完整备份的目标合并分析已复用单命例的模块去重数量与逐字段前后值规则。
- 完整恢复执行会重新认证同一备份、复核冲突和目标修订，重建全部子项身份；附件进入
  事务专属目录并校验字节数与哈希，数据库失败时回滚并移除本次新增附件。
- 恢复日志可在 App 启动时清理未提交附件或确认已提交附件；事实不一致时停止自动处理
  并保留现场，不做猜测性删除。
- API 35 两阶段设备测试已真实强杀持有恢复边界的 App 进程，并由不同 PID 冷启动验证
  日志、暂存和最终孤儿附件自动清除；脚本拒绝在非模拟器序列号上运行。
- 完整恢复采用全屏惰性列表工作台，持续显示已决策数量、逐例冲突与底部阶段动作；批量
  跳过是明确用户动作，只设置逐例决策，不会直接提交。

当前 UI 已覆盖命例生命周期、Stage 3B 数据交换、历法/地区/DST/真太阳时、问真
P0/P1/P2 截图迁移、四主入口与详情四标签。Stage 7A–7D 已接入完整流年序列、精确当前
大运，以及按立春、交节、子时口径计算的流年、流月、流日、流时；观察时分、前后节气、
计算档案和规则版本均可审计并可复制诊断。专业细盘截图的观察时刻和九列干支会保留
来源证据，正式提交后逐字段保存本机复算值与一致性。真实问真样本与 OPPO 真机仍需
用户授权验收。基本排盘截图的主星、藏干、副星、星运、自坐、空亡、纳音、生肖与
星座也会在提交后保存本机计算值；神煞当前只保留来源证据。

## 本机构建

```bash
JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" \
  ./gradlew test assembleDebug lintDebug
```

Debug APK 由 `app` 模块生成，名称包含平台、版本和 Debug 标记。模拟器验证与
OPPO 真机、真实问真资料验收必须分开报告。
